## 2,000/300 机制验证

30 次主消融、9 次 SAM2.1 和 3 次 Q80 全部完成。每组 10,000 次更新及五轮验证。原生 SAM3.1 LoRA 是强基线，验证选模规则对每组独立应用。

|主消融配置|三种子 best 验证实例 IoU %|三种子 best 验证 PQ %|
|---|---:|---:|
|A|57.72|31.83|
|B|57.73|32.26|
|C|59.92|32.23|
|S（原生 LoRA）|81.21|71.19|

B−A 的验证实例 IoU 配对差为 +3.70、−2.22、−1.42 个百分点。C−B 为 −1.98、+3.98、+4.54 个百分点。这批验证结果没有显示 tracker 稳定优于 A。种子 42 的正式合成测试 best 实例 IoU 为 A 62.96%、B 64.53%、C 62.43%，对应 PQ 为 37.23%、34.80%、35.64%。三种子正式测试和真实集结论要用完整收据汇总。

**训练证据。** [训练汇总](pilot/training/summary.csv) 和 [逐轮验证](pilot/training/epochs.csv) 列出 42 组。各组目录包含参数来源、损失权重、更新与采样统计、逐验证图指标和全部 PNG/PDF/CSV 曲线。较大的 CSV 和 JSON 用标准 gzip 压缩。每个发布的模型都绑定 [best/last checkpoint 哈希](pilot/training/checkpoints.csv) 和对应源码 SHA。旧 A/B/C/D 的独立结果放在 [original_pilot](pilot/original_pilot/)。

**正式评测。** 当前有 17 份固定合成测试报告、8 份受控遮挡评测、8 份效率报告。共 33 项全部有通过收据。各任务目录保留逐图/逐事件指标、难度分层、支持区域诊断或计时观测。数值报告中的原生诊断文件名是原始产物的引用；分支没有镜像每张输入图、原始 attention 张量或预测掩码。公开 JSON 的机器路径已改为占位符，receipt 里的哈希指原始服务器字节。[快照、待测清单](pilot/evaluation/snapshot.json) · [来源收据](pilot/evaluation/task_receipts.json) · [固定测试汇总](pilot/evaluation/synthetic_summary.csv)
